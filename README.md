# Counter-Offer

Counter-Offer is a web-based roleplay game powered by the Vercel AI SDK, Next.js, and Google's Gemini Flash. Step into the shoes of a job candidate and negotiate your starting salary with a stubborn, AI-driven Hiring Manager.

## The Goal
Your objective is to negotiate a 20% increase on your starting salary offer. The AI will utilize realistic HR pushbacks—such as budget constraints and internal equity—testing your persuasion tactics.

## Tech Stack
* Next.js (App Router)
* Tailwind CSS
* Vercel AI SDK
* Google Gemini

## Setup
1. Clone the repository.
2. Run `npm install`.
3. Rename `.env.example` to `.env.local` and add your `GOOGLE_API_KEY`.
4. Run `npm run dev` to start the development server.

## Design
Strictly follows the Hizaki Labs design system utilizing specific Indigo and Accent Green palettes alongside `Inter` and `Space Grotesk` typography.
